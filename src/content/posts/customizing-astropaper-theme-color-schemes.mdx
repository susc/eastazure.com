本指南介绍如何启用或禁用深浅色模式，以及如何自定义整个网站的配色方案。

## 目录

## 启用／禁用深浅色模式

AstroPaper 主题默认包含浅色和深色模式。你可以在 `astro-paper.config.ts` 中关闭这一默认行为：

```ts file="astro-paper.config.ts"
export default defineAstroPaperConfig({
  // ...
  features: {
    lightAndDarkMode: true, // [!code highlight]
    // ...
  },
});
```

如需禁用深浅色模式，请将 `features.lightAndDarkMode` 设置为 `false`。禁用后，网站只会使用 `src/styles/theme.css` 中定义的浅色配色。

## 自定义配色方案

AstroPaper 的浅色和深色配色都定义在 `src/styles/theme.css` 中。

```css file="src/styles/theme.css"
/* 浅色主题变量 */
:root,
[data-theme="light"] {
  --background: #fdfdfd;
  --foreground: #282728;
  --accent: #006cac;
  --accent-foreground: #ffffff;
  --muted: #e6e6e6;
  --muted-foreground: #6b7280;
  --border: #ece9e9;
}

/* 深色主题变量 */
[data-theme="dark"] {
  --background: #212737;
  --foreground: #eaedf3;
  --accent: #ff6b01;
  --accent-foreground: #ffffff;
  --muted: #343f60;
  --muted-foreground: #afb9ca;
  --border: #ab4b08;
}
```

`:root` 和 `[data-theme="light"]` 选择器定义浅色配色，`[data-theme="dark"]` 则定义深色配色。

要自定义配色，请在 `:root, [data-theme="light"]` 中指定浅色模式颜色，并在 `[data-theme="dark"]` 中指定深色模式颜色。

下面详细说明各个颜色属性：

<ResponsiveTable variant="minimal" class="max-sm:-mx-4 [&_td]:first-of-type:text-nowrap">

| 颜色属性              | 定义与用途                                           |
| --------------------- | ---------------------------------------------------- |
| `--background`        | 网站的主色，通常用作主要背景。                       |
| `--foreground`        | 网站的前景色，通常用作文本颜色。                     |
| `--accent`            | 强调色，用于链接、悬停状态和交互元素。               |
| `--accent-foreground` | 显示在 `--accent` 背景之上的前景色。                 |
| `--muted`             | 柔和背景色，用于卡片、标签和悬停状态。               |
| `--muted-foreground`  | 显示在 `--muted` 背景之上的文本颜色。                |
| `--border`            | 边框颜色，用于分隔线和视觉区域划分。                 |

</ResponsiveTable>

下面是修改浅色配色的示例：

```css file="src/styles/theme.css"
/* ... */
:root,
[data-theme="light"] {
  --background: #f6eee1;
  --foreground: #012c56;
  --accent: #e14a39;
  --accent-foreground: #ffffff;
  --muted: #efd8b0;
  --muted-foreground: #6b7280;
  --border: #dc9891;
}
/* ... */
```

> 你也可以查看 AstroPaper 已经准备好的[预设配色方案](https://astro-paper.pages.dev/posts/predefined-color-schemes/)。
