本指南介绍 AstroPaper 提供的配置选项，包括网站元数据、功能开关、字体、社交链接和布局设置。

## 目录

## 配置 astro-paper.config.ts

所有全站配置都位于项目根目录的 `astro-paper.config.ts`。使用 `defineAstroPaperConfig()` 可获得完整的智能提示：

```ts file="astro-paper.config.ts"
import { defineAstroPaperConfig } from "./src/types/config";

export default defineAstroPaperConfig({
  site: {
    url: "https://your-site.com/", // 替换为实际部署地址
    title: "AstroPaper",
    description: "一个极简、响应式且 SEO 友好的 Astro 博客主题。",
    author: "Sat Naing",
    profile: "https://satnaing.dev",
    ogImage: "default-og.jpg",
    lang: "zh-CN",
    timezone: "Asia/Shanghai",
    dir: "ltr",
  },
  posts: {
    perPage: 4,
    perIndex: 4,
    scheduledPostMargin: 15 * 60 * 1000, // 15 分钟
  },
  features: {
    lightAndDarkMode: true,
    dynamicOgImage: true,
    showArchives: true,
    showBackButton: true,
    editPost: {
      enabled: true,
      url: "https://github.com/satnaing/astro-paper/edit/main/",
    },
    search: "pagefind",
  },
  socials: [
    { name: "github", url: "https://github.com/satnaing/astro-paper" },
    { name: "x", url: "https://x.com/username" },
    { name: "linkedin", url: "https://www.linkedin.com/in/username/" },
    { name: "mail", url: "mailto:yourmail@gmail.com" },
  ],
  shareLinks: [
    { name: "whatsapp", url: "https://wa.me/?text=" },
    { name: "facebook", url: "https://www.facebook.com/sharer.php?u=" },
    { name: "x", url: "https://x.com/intent/post?url=" },
    { name: "telegram", url: "https://t.me/share/url?url=" },
    { name: "mail", url: "mailto:?subject=See%20this%20post&body=" },
  ],
});
```

### `site` 选项

<ResponsiveTable>

| 选项                 | 说明                                                                                                                              |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `url`                | 部署后的网站 URL，用于规范 URL、OG 图片 URL、RSS 和站点地图。生产环境中必须正确设置。                                             |
| `title`              | 网站名称。                                                                                                                        |
| `description`        | 网站描述，用于 SEO 和社交媒体分享。                                                                                               |
| `author`             | 你的名字，用作默认文章作者。                                                                                                      |
| `profile`            | 个人／作品集网站 URL，用于结构化数据。如果没有，请设为 `undefined`。                                                              |
| `ogImage`            | `/public` 中的默认 OG 图片文件名，例如 `"default-og.jpg"`。未设置文章图片且禁用 `dynamicOgImage` 时使用。                         |
| `lang`               | `<html lang="...">` 使用的 ISO 语言代码，默认值为 `"en"`。                                                                     |
| `timezone`           | 文章日期使用的 IANA 时区，例如 `"Asia/Shanghai"`，确保本地与部署环境的时间一致。                                                 |
| `dir`                | `<html dir="...">` 的文本方向，支持 `"ltr"`、`"rtl"` 或 `"auto"`。                                                          |
| `googleVerification` | Google Search Console 验证 Meta 标签值，可选。优先级高于 `PUBLIC_GOOGLE_SITE_VERIFICATION` 环境变量。                              |

</ResponsiveTable>

### `posts` 选项

<ResponsiveTable>

| 选项                  | 说明                                                                                                  |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| `perPage`             | 分页列表每页显示的文章数，默认值为 `4`。                                                             |
| `perIndex`            | 首页“最新文章”区域显示的文章数，默认值为 `4`。                                                       |
| `scheduledPostMargin` | 发布时间在当前时间之后但位于此窗口（毫秒）内的文章会视为已发布，默认值为 15 分钟（`15 * 60 * 1000`）。 |

</ResponsiveTable>

### `features` 选项

<ResponsiveTable>

| 选项                | 说明                                                                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lightAndDarkMode` | 启用或禁用深浅色模式切换，默认值为 `true`。                                                                                                        |
| `dynamicOgImage`   | frontmatter 中未指定 `ogImage` 时，为每篇文章动态生成 OG 图片，默认值为 `true`。详情请参阅[相关取舍](https://astro-paper.pages.dev/posts/dynamic-og-image-generation-in-astropaper-blog-posts/#trade-off)。 |
| `showArchives`     | 显示 `/archives` 页面及页眉链接，默认值为 `true`。                                                                                                 |
| `showBackButton`   | 在文章页面显示“返回”按钮，默认值为 `true`。                                                                                                        |
| `editPost`         | 在文章标题下显示“编辑页面”链接。请设置 `enabled: true`，并提供仓库编辑 URL 的基础 `url`。可通过文章 frontmatter 的 `hideEditPost` 单独覆盖。          |
| `search`           | 搜索提供程序，默认值为 `"pagefind"`。设置为 `false` 可完全禁用搜索。                                                                               |

</ResponsiveTable>

## 更新布局宽度

整个博客默认的 `max-width` 为 `768px`（`max-w-3xl`）。如需修改，请更新 `src/styles/global.css` 中的 `max-w-app` 工具类：

```css file="src/styles/global.css"
@utility max-w-app {
  /* [!code --:1] */
  @apply max-w-3xl;
  /* [!code ++:1] */
  @apply max-w-4xl xl:max-w-5xl;
}
```

更多 `max-width` 值请参阅 [Tailwind CSS 文档](https://tailwindcss.com/docs/max-width)。

## 配置 Logo 或标题

![箭头指向网站 Logo](https://res.cloudinary.com/noezectz/v1663911318/astro-paper/AstroPaper-logo-config_goff5l.png)

你可以选择以下三种方案。

### 方案一：网站标题文本

这是最简单的方案，只需更新 `astro-paper.config.ts` 中的 `site.title`。

### 方案二：Astro SVG 组件

如果希望使用 SVG Logo，可以选择此方案。

- 首先，在 `src/assets/` 目录中添加 SVG，例如 `src/assets/dummy-logo.svg`；
- 然后，在 `Header.astro` 中导入该 SVG：

  ```astro file="src/components/Header.astro"
  ---
  // ...
  import DummyLogo from "@/assets/dummy-logo.svg";
  ---
  ```

- 最后，用导入的 Logo 替换 `{config.site.title}`：

  ```html
  <a
    href="/"
    class="absolute py-1 text-left text-2xl leading-7 font-semibold whitespace-nowrap sm:static"
  >
    <DummyLogo class="scale-75 dark:invert" />
    <!-- {config.site.title} -->
  </a>
  ```

这种方案最大的优点是可以根据需要自定义 SVG 样式。上例展示了如何在深色模式中反转 SVG Logo 的颜色。

### 方案三：Astro Image 组件

如果 Logo 是非 SVG 图片，可以使用 Astro Image 组件。

- 将 Logo 放入 `src/assets/`，例如 `src/assets/dummy-logo.png`；
- 在 `Header.astro` 中导入 `Image` 和 Logo：

  ```astro file="src/components/Header.astro"
  ---
  // ...
  import { Image } from "astro:assets";
  import dummyLogo from "@/assets/dummy-logo.png";
  ---
  ```

- 然后，用导入的 Logo 替换 `{config.site.title}`：

  ```html
  <a
    href="/"
    class="absolute py-1 text-left text-2xl leading-7 font-semibold whitespace-nowrap sm:static"
  >
    <image src="{dummyLogo}" alt="我的博客" class="dark:invert" />
    <!-- {config.site.title} -->
  </a>
  ```

这种方式仍可通过 CSS 类调整图片外观，但不一定适合所有需求。如果需要根据深浅色模式显示不同的 Logo 图片，可以参考 `Header.astro` 组件中深浅色图标的处理方式。

## 配置社交链接

![箭头指向社交链接图标](https://github.com/user-attachments/assets/8b895400-d088-442f-881b-02d2443e00cf)

社交链接在 `astro-paper.config.ts` 的 `socials` 数组中配置。每一项都需要一个 `name` 和一个 `url`，其中 `name` 必须与 `src/assets/icons/socials/` 中的 SVG 文件名匹配：

```ts file="astro-paper.config.ts"
export default defineAstroPaperConfig({
  // ...
  socials: [
    { name: "github", url: "https://github.com/satnaing/astro-paper" },
    { name: "x", url: "https://x.com/username" },
    { name: "linkedin", url: "https://www.linkedin.com/in/username/" },
    { name: "mail", url: "mailto:yourmail@gmail.com" },
  ],
});
```

如需添加默认列表以外的社交平台，请把它的 SVG 图标添加到 `src/assets/icons/socials/`，再向数组添加一项。`name` 必须与不含 `.svg` 扩展名的文件名一致。

## 配置分享链接

![箭头指向分享链接图标](https://github.com/user-attachments/assets/4f930b68-b625-45df-8c41-e076dd2b838e)

分享链接在 `shareLinks` 数组中配置。每一项都需要 `name`（与 `src/assets/icons/socials/` 中的 SVG 匹配）和基础 `url`，文章 URL 会追加到该地址之后：

```ts file="astro-paper.config.ts"
export default defineAstroPaperConfig({
  // ...
  shareLinks: [
    { name: "whatsapp", url: "https://wa.me/?text=" },
    { name: "facebook", url: "https://www.facebook.com/sharer.php?u=" },
    { name: "x", url: "https://x.com/intent/post?url=" },
    { name: "telegram", url: "https://t.me/share/url?url=" },
    { name: "mail", url: "mailto:?subject=See%20this%20post&body=" },
  ],
});
```

## 配置字体

AstroPaper 使用 Astro 的 [Fonts API](https://docs.astro.build/en/guides/fonts/)，默认字体为 [Google Sans Code](https://fonts.google.com/specimen/Google+Sans+Code)。它通过预加载和缓存等自动字体优化，在各个平台上提供一致的排版效果。

### 使用默认字体

字体已在 `astro.config.ts` 中自动配置，并在 `Layout.astro` 中加载。使用默认 Google Sans Code 字体无需额外配置。

### 自定义字体

要使用其他字体，需要更新三个位置。

1. **更新 `astro.config.ts` 中的字体配置：**

```ts file="astro.config.ts"
import { defineConfig, fontProviders } from "astro/config";

export default defineConfig({
  // ...
  fonts: [
    {
      name: "Your Font Name", // [!code highlight]
      cssVariable: "--font-your-font", // [!code highlight]
      provider: fontProviders.google(),
      fallbacks: ["monospace"],
      weights: [300, 400, 500, 600, 700],
      styles: ["normal", "italic"],
    },
  ],
});
```

2. **更新 `Layout.astro` 中的 Font 组件：**

```astro file="src/layouts/Layout.astro"
---
import { Font } from "astro:assets";
// ...
---

<head>
  <!-- ... -->
  <Font
    cssVariable="--font-your-font"
    preload={[{ subset: "latin", weight: 400, style: "normal" }]}
  />
  <!-- ... -->
</head>
```

3. **更新 `src/styles/theme.css` 中的 CSS 变量映射：**

```css file="src/styles/theme.css"
@theme inline {
  --font-app: var(--font-your-font); /* [!code highlight] */
  /* ... */
}
```

整个主题通过 Tailwind 的 `font-app` 工具类使用 `--font-app` 变量，因此只需更新这一处变量，即可在全站应用自定义字体。

> [!WARNING]
> 请确保字体名称与 [Google Fonts](https://fonts.google.com) 上显示的名称完全一致。如果使用其他字体提供商或本地字体，请参阅 [Astro Fonts 文档](https://docs.astro.build/en/guides/fonts/)。
